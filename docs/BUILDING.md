# Сборка и выпуск

## Требования

- Windows x64.
- .NET Framework 4.8.1.
- PowerShell.

Пакеты NuGet не нужны. Компилятор C# входит в .NET Framework.

## Локальная сборка и проверки

Запустите из корня проекта:

~~~powershell
.\Check-Local.ps1
~~~

Скрипт собирает приложение и SelfCheck, затем запускает быстрые локальные проверки.
Готовое приложение появится в dist/CodexUsageTray.exe.
Исполняемый файл SelfCheck появится в build/checks/SelfCheck.exe.

Каталоги build/ и dist/ исключены из Git. Не добавляйте их содержимое в коммиты.

## Публикация

Создайте GitHub Release для нового тега и прикрепите dist/CodexUsageTray.exe как asset.
Не коммитьте бинарный файл в исходный репозиторий.
GitHub Release также предоставляет архив исходников для выбранного тега.
